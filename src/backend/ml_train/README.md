# 代谢综合征预测模型

这个项目使用机器学习方法基于给定的特征预测一个人是否患有代谢综合征。模型采用了特征工程、特征选择和集成学习等技术，以提高预测准确率。

## 数据集

使用`Metabolic Syndrome.csv`数据集，该数据集包含以下特征：
- 人口统计学特征：年龄、性别、婚姻状况、收入、种族
- 健康指标：腰围、BMI、白蛋白尿、尿白蛋白肌酐比值、尿酸、血糖、高密度脂蛋白胆固醇、甘油三酯
- 目标变量：MetabolicSyndrome（0或1）

## 特征处理

- 收入(Income)被分为三类：
  - Low: < 3000
  - Mid: >= 3000 且 <= 6000
  - High: > 6000
- 特征工程：
  - 创建了腰围与BMI的比率
  - 创建了血糖与HDL的比率
  - 创建了甘油三酯与HDL的比率
  - 根据年龄创建了年龄组
- 特征选择：
  - 使用随机森林的特征重要性进行特征选择
  - 仅保留重要性超过阈值的特征

## 模型优化

- 交叉验证：使用5折交叉验证评估多种模型
- 模型比较：比较了随机森林、梯度提升、逻辑回归和支持向量机
- 超参数调优：使用网格搜索找到最佳模型参数
- 集成学习：将多个模型结合构建集成模型，提高预测准确率

## 可视化功能

项目提供了丰富的可视化功能：
1. 特征重要性可视化
2. 混淆矩阵热图
3. ROC曲线和AUC值
4. 精确率-召回率曲线
5. 类别分布图
6. 特征与目标变量关系图
7. 个人预测概率条形图
8. 个人健康指标雷达图

## 项目文件

- `train_model.py`: 训练代谢综合征预测模型并保存模型
- `predict.py`: 使用训练好的模型进行预测并可视化结果
- `Metabolic Syndrome.csv`: 原始数据集
- `model/`: 保存训练的模型和相关文件
  - `metabolic_syndrome_model.pkl`: 训练好的模型
  - `label_encoders.pkl`: 类别编码器
  - `scaler.pkl`: 特征标准化器
  - `feature_selector.pkl`: 特征选择器
  - `selected_features.pkl`: 选择的特征列表
- `plots/`: 保存模型训练过程中生成的可视化图表
- `predictions/`: 保存个人预测结果的可视化图表

## 使用方法

### 1. 训练模型

```bash
python train_model.py
```

这将使用数据集训练模型，并保存模型到`model/`文件夹中，同时生成可视化图表保存到`plots/`文件夹。

### 2. 进行预测

```bash
python predict.py
```

按照提示输入各项指标，程序会返回预测结果和相应的概率，并生成个人健康状况的可视化图表保存到`predictions/`文件夹。

### 注意事项

- 输入的收入类别必须是"Low", "Mid"或"High"之一
- 输入的性别必须是"Male"或"Female"
- 输入的婚姻状况必须与训练数据集中的值一致（如"Single", "Married", "Divorced", "Widowed"等）
- 输入的种族必须与训练数据集中的值一致（如"White", "Black", "Asian"等）
