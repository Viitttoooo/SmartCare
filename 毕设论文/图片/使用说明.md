# 图片合成工具使用说明

这是一个使用 Matplotlib 将多张图片合并为一张图片的工具。

## 功能特点

1. 支持2-4张图片的合并
2. 可以为每个子图指定标题
3. 支持从指定文件夹中选择图片进行合并

## 依赖库

使用前请确保安装了以下 Python 库：

```bash
pip install matplotlib Pillow numpy
```

## 使用方法

### 方法一：直接在脚本中修改示例代码

1. 打开 `图片合成工具.py` 文件
2. 找到 `if __name__ == "__main__":` 部分
3. 取消注释示例1或示例2的代码块
4. 根据需要修改图片路径、标题和输出路径
5. 运行脚本：`python 图片合成工具.py`

### 方法二：在其他代码中导入使用

```python
from 图片合成工具 import merge_images, merge_images_from_folder

# 示例1：直接指定图片路径合并
image_paths = [
    "./代码图/图片1.png",
    "./代码图/图片2.png",
    "./代码图/图片3.png"
]
subplot_titles = ["图片1标题", "图片2标题", "图片3标题"]
merge_images(image_paths, subplot_titles, "合并结果.png")

# 示例2：从文件夹选择图片合并
folder_path = "./代码图"
image_names = ["图片1.png", "图片2.png", "图片3.png", "图片4.png"]
subplot_titles = ["图片1标题", "图片2标题", "图片3标题", "图片4标题"]
merge_images_from_folder(folder_path, image_names, subplot_titles, "合并结果.png")
```

## 注意事项

1. 图片数量必须在2-4张之间
2. 子图标题数量必须与图片数量一致
3. 输出路径参数可选，若不提供则显示图片而不保存
4. 建议使用相似尺寸的图片以获得最佳显示效果

## 布局说明

- 2张图片：1行2列排列
- 3张图片：上方2张并排，下方1张居中
- 4张图片：2行2列网格排列
